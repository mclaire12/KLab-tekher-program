# AI Document Reader — NLP Baseline Version

Part 1 of a two-part university NLP/ML project: an AI Document Reader that
uploads PDF/DOCX/TXT documents, extracts and preprocesses the text, detects its
language (English / French / Kinyarwanda) with a **TF-IDF + machine-learning**
classifier, summarises it, answers questions about it, and reads it aloud.
